# rsync 常用操作指南

> 最后更新：2026-11-19  
> 适用系统：Linux / macOS / Windows（WSL 或 Cygwin）

`rsync` 是最常用的增量同步工具，支持本地、远程（SSH）同步，高效、可断点续传、可精确控制。

---

## 1. 基本语法

```bash
rsync [选项] 源路径 目标路径
```

- **源路径末尾加 `/`**：表示同步**目录内容**
- **源路径末尾不加 `/`**：表示同步**整个目录**

```bash
# 同步目录内容
rsync -avh src/ dest/

# 同步整个目录
rsync -avh src dest/
```

---

## 2. 最常用选项速查

| 选项 | 含义 | 推荐程度 |
|------|------|----------|
| `-a` | 归档模式（等价于 `-rlptgoD`） | ★★★★★ |
| `-v` | 显示详细过程 | ★★★★★ |
| `-h` | 人类可读的文件大小 | ★★★★★ |
| `--progress` | 显示每个文件传输进度 | ★★★★★ |
| `-P` | 等价于 `--progress --partial`（推荐） | ★★★★★ |
| `-z` | 传输时压缩（网络慢时有用） | ★★★★☆ |
| `--delete` | 删除目标中源没有的文件 | ★★★★☆ |
| `-n` / `--dry-run` | 只预览，不实际执行 | ★★★★★ |
| `--exclude` | 排除文件/目录 | ★★★★★ |
| `--exclude-from` | 从文件读取排除规则 | ★★★★☆ |
| `-e ssh` | 指定使用 SSH（默认已是） | ★★★☆☆ |
| `--bwlimit=KB/s` | 限制带宽 | ★★★☆☆ |
| `--partial` | 保留未完成的文件（断点续传） | ★★★★☆ |
| `--info=progress2` | 显示总体进度（较新版本） | ★★★★☆ |

### 最推荐的日常组合

```bash
rsync -avhP --progress
```

或更简洁：

```bash
rsync -avhP
```

## 3. 常用场景

### 3.1 本地 → 远程（推送）

```bash
rsync -avhP /本地路径/ user@remote:/远程路径/
```

### 3.2 远程 → 本地（拉取）

```bash
rsync -avhP user@remote:/远程路径/ /本地路径/
```

### 3.3 增量同步（默认行为）

只传输有变化的文件，已存在且未修改的文件会跳过。

### 3.4 完全同步（删除目标多余文件）

```bash
rsync -avhP --delete 源/ 目标/
```

> **警告**：使用前务必先加 `--dry-run` 预览！

### 3.5 预览将要执行的操作（强烈推荐）

```bash
rsync -avhP --delete --dry-run 源/ 目标/
```

### 3.6 排除文件/目录

```bash
# 排除单个目录
rsync -avhP --exclude='.git' --exclude='node_modules' 源/ 目标/

# 排除多种文件
rsync -avhP --exclude='*.log' --exclude='*.tmp' --exclude='.DS_Store' 源/ 目标/

# 从文件读取排除规则
rsync -avhP --exclude-from='exclude.txt' 源/ 目标/
```

`exclude.txt` 示例：
```
.git/
node_modules/
*.log
.DS_Store
```

### 3.7 限速传输

```bash
# 限制为 10MB/s（10240 KB/s）
rsync -avhP --bwlimit=10240 源/ 目标/
```

### 3.8 保留权限和所有者（需要 root）

```bash
sudo rsync -avhP --delete 源/ 目标/
```

### 3.9 显示总体进度（推荐）

```bash
rsync -avhP --info=progress2 源/ 目标/
```

## 4. 实用示例

### 4.1 同步 Ollama 模型目录

```bash
# 从 Mac 推送到 Ubuntu
rsync -avhP ~/.ollama/models/ larry@matrixstorm:/usr/share/ollama/.ollama/models/

# 从 Ubuntu 拉回 Mac
rsync -avhP larry@matrixstorm:/usr/share/ollama/.ollama/models/ ~/.ollama/models/
```

### 4.2 同步时排除临时文件

```bash
rsync -avhP \
  --exclude='*.partial' \
  --exclude='.tmp' \
  ~/.ollama/models/ \
  user@remote:/path/to/models/
```

### 4.3 断点续传（网络不稳定时）

```bash
rsync -avhP --partial --append-verify 源/ 目标/
```

### 4.4 只同步特定扩展名

```bash
rsync -avhP --include='*.gguf' --include='*/' --exclude='*' 源/ 目标/
```

---

## 5. 安全建议

1. **永远先加 `--dry-run`** 预览，尤其是使用 `--delete` 时。
2. 同步系统目录时建议使用 `sudo`。
3. 远程同步优先使用 SSH 密钥认证，避免每次输入密码。
4. 重要数据同步前先备份。
5. 大文件传输建议加上 `-z`（压缩）或使用 `--bwlimit` 避免占满带宽。

---

## 6. 常见问题

| 问题 | 解决方法 |
|------|----------|
| 权限不足 | 使用 `sudo rsync` |
| 传输中断 | 使用 `-P` 或 `--partial`，重新运行即可续传 |
| 速度很慢 | 加 `-z` 压缩，或检查是否走了不必要的加密 |
| 目标多余文件没删除 | 加上 `--delete` |
| 想只看变化不实际执行 | 加上 `--dry-run` |
