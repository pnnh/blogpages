# Emacs 新手指南：常用快捷键与操作方式

> 目标读者：第一次打开 Emacs、或只用过方向键和菜单的人。  
> 读完后你应能：打开/保存文件、在缓冲区之间切换、分屏、搜索替换、用帮助系统自学，并且在卡住时知道如何取消。

Emacs 不是“又一个记事本”，而是一套以**命令**为中心的可扩展编辑环境。快捷键只是调用命令的快捷方式；几乎所有操作都可以用 `M-x 命令名` 完成。记住这一点，后面就不会把 Emacs 当成“必须死记硬背的键位表”。

官方交互教程始终是最好的第一步：启动 Emacs 后按 **`C-h t`**。本文相当于那份教程的中文导读与速查，并补上新手最容易卡的概念。

---

## 1. 启动、界面与三个必须分清的词

### 1.1 怎么启动

- 图形界面：终端或启动器里运行 `emacs`
- 纯终端（SSH、没有桌面时）：`emacs -nw`（`--no-window-system`）
- 第一次启动会看到欢迎屏（`*GNU Emacs*` 缓冲区），可以立刻按 `C-h t` 进教程，或 `C-x C-f` 打开文件

配置文件通常是 `~/.emacs.d/init.el` 或 `~/.emacs`。新手**先不要改配置**，用默认键位把肌肉记忆建立起来。

### 1.2 三个容易混的概念

| 概念 | 是什么 | 类比 |
|------|--------|------|
| **Buffer（缓冲区）** | 内存里的一份文本（可能对应磁盘文件，也可能是 `*scratch*`、`*Messages*`、`*Help*` 这类临时内容） | 打开的文档本身 |
| **Window（窗口）** | 屏幕上显示某个缓冲区的一块区域 | 分屏后的窗格 |
| **Frame（帧）** | 操作系统意义上的一个 Emacs 顶层窗口 | 整个应用窗口 |

要点：

- 一个缓冲区可以同时出现在多个窗口里。
- 关掉窗口（`C-x 0`）**不等于**关掉缓冲区；关掉缓冲区用 `C-x k`。
- 状态栏（mode line）会显示：当前缓冲区名、主模式、只读/修改标记、行列等。
- 最底下那一行是 **minibuffer（迷你缓冲区）**：打开文件、搜命令、提问都在这里进行。

### 1.3 Point、Mark 与 Region

- **Point**：光标所在位置（插入点）。
- **Mark**：你用 `C-SPC`（`set-mark-command`）打下的另一个标记。
- **Region**：point 与 mark 之间的区域。许多命令（剪切、缩进、大小写）都作用于 region。

在图形界面里，用鼠标拖选也会设置 region。终端里更依赖 `C-SPC` 再移动光标。

> 中文输入法注意：许多系统把 `C-SPC` 占用成“切换输入法”。可改用 **`C-@`**（同一个命令），或把输入法热键改掉。

## 2. 按键记法：先学会读，再学会按

Emacs 文档里的写法与键盘上看到的不一样：

| 写法 | 含义 | 怎么按 |
|------|------|--------|
| `C-x` | Control + x | 按住 Ctrl，再按 x |
| `M-x` | Meta + x | 通常是 **Alt + x**；没有 Meta 时先按再松开 **Esc**，再按 x |
| `C-M-x` | Control + Meta + x | Ctrl 和 Alt 同时按住，再按 x |
| `C-x C-f` | 先 `C-x`，松开后立刻 `C-f` | 这是**前缀键**序列，不是同时按三个键 |
| `RET` | 回车 | Enter |
| `DEL` / `BACKSPACE` | 删除光标前一个字符 | 退格 |
| `SPC` | 空格 | |
| `TAB` | 补全或缩进 | 视上下文而定 |

四个最重要的前缀：

- **`C-x`**：文件、缓冲区、窗口等“全局管理”
- **`C-c`**：当前主模式的专用命令（例如 Org、编程模式）
- **`C-h`**：帮助
- **`M-x`**：按名字执行任意命令

前缀敲了一半却忘了下一步？再按一次 **`C-h`**，Emacs 会列出这个前缀后面还能跟哪些键（装了 `which-key` 包后会更友好）。想取消整串输入，按 **`C-g`**。

## 3. 救命三键：卡死时先按它们

把这三组练到不假思索：

| 快捷键 | 命令 | 作用 |
|--------|------|------|
| **`C-g`** | `keyboard-quit` | 取消正在进行的命令、关掉迷你缓冲区提问、打断卡死的操作 |
| **`C-/`** 或 `C-_` 或 `C-x u` | `undo` | 撤销。可连续按；Emacs 的撤销是一条历史链 |
| **`C-h t`** | `help-with-tutorial` | 打开内置教程 |

相关恢复手段：

- 屏幕花了、光标看起来“丢了”：`C-l`（重绘并把当前行放到窗口中部；连按会在中/上/下之间切换）
- 误改了很多、想回到磁盘上的版本：`M-x revert-buffer`
- 崩溃后恢复自动保存：`M-x recover-session`
- 暂时挂起（终端）或最小化（图形）：`C-z`；彻底退出：`C-x C-c`（会询问未保存缓冲区）

**原则：先 `C-g`，再思考。** 不要狂按 Esc 或 Ctrl-C——后者在 Emacs 里是模式前缀，不是“强制退出”。

## 4. 移动光标：比方向键更值得练的一组

方向键能用，但 Emacs 原生移动键让手不用离开字母区，并与“按语义单位移动/删除”配套。

### 4.1 按字符、词、行

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-f` / `C-b` | `forward-char` / `backward-char` | 前进 / 后退一个字符 |
| `C-n` / `C-p` | `next-line` / `previous-line` | 下一行 / 上一行 |
| `C-a` / `C-e` | `move-beginning-of-line` / `move-end-of-line` | 行首 / 行尾 |
| `M-f` / `M-b` | `forward-word` / `backward-word` | 下一个 / 上一个词 |
| `M-m` | `back-to-indentation` | 跳到本行第一个非空白字符（写代码很常用） |
| `M-a` / `M-e` | `backward-sentence` / `forward-sentence` | 句首 / 句尾 |
| `M-{` / `M-}` | `backward-paragraph` / `forward-paragraph` | 上一段 / 下一段 |

中文文本里“词”的边界不如英文清晰，`M-f` / `M-b` 对汉字往往按字或按 Emacs 的 word 语法表移动；写中文时更常靠行、段和搜索定位。

### 4.2 按屏、按整个缓冲区

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-v` / `M-v` | `scroll-up-command` / `scroll-down-command` | 向下 / 向上翻一屏 |
| `C-l` | `recenter-top-bottom` | 重绘并滚动当前行到中/上/下 |
| `M-<` / `M->` | `beginning-of-buffer` / `end-of-buffer` | 缓冲区开头 / 结尾 |
| `M-g g` 或 `M-g M-g` | `goto-line` | 跳到指定行号 |
| `M-g c` | `goto-char` | 跳到指定字符位置 |

### 4.3 数值前缀（重复 N 次）

`C-u` 后面跟数字，再跟命令，表示重复或给参数。例如：

- `C-u 10 C-n`：向下 10 行
- `C-u 20 C-f`：向前 20 个字符
- 只按 `C-u` 再按命令，默认参数往往是 4（例如 `C-u C-n` 下移 4 行）
- `C-u C-u` 一般是 16，可叠加

很多命令“带参数时行为会变”，这是 Emacs 的常见设计，不必一次记完，用 `C-h k` 看每个命令的文档即可。

## 5. 编辑：删除、杀死、粘贴与区域

Emacs 把“删掉且丢掉”和“剪下来以后还能贴回去”分开。后者叫 **kill**，对应的粘贴叫 **yank**。被 kill 的文本进入 **kill-ring**（一个环形剪贴板），可以连续召回更早的条目。

### 5.1 删除与杀死

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `DEL` / Backspace | `delete-backward-char` | 删光标前一个字符（通常不进 kill-ring） |
| `C-d` | `delete-char` | 删光标后一个字符 |
| `C-k` | `kill-line` | 从光标杀到行尾；行尾已空时再按一次会连换行一起杀掉 |
| `C-w` | `kill-region` | 杀掉 region（剪切） |
| `M-w` | `kill-ring-save` | 把 region 拷进 kill-ring（复制，不删除） |
| `M-d` | `kill-word` | 杀掉光标后一个词 |
| `M-DEL` | `backward-kill-word` | 杀掉光标前一个词 |
| `C-x h` | `mark-whole-buffer` | 选中整个缓冲区，再 `C-w` / `M-w` |

选定区域的标准手法：

1. 把光标移到起点，按 `C-SPC`（或 `C-@`）
2. 移动光标到终点（此时 mode line 常显示 `Mark activated`）
3. `C-w` 剪切或 `M-w` 复制

取消激活的 mark：再按一次 `C-g`，或 `C-SPC C-SPC`。

### 5.2 粘贴（Yank）与 kill-ring

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-y` | `yank` | 粘贴最近一次 kill 的内容 |
| `M-y` | `yank-pop` | **必须紧跟在 `C-y` 之后**，换成 kill-ring 里更早的一条 |

可以理解为：`C-y` 贴最新的，然后连按 `M-y` 在历史里往后翻。这比系统剪贴板更适合“刚剪了三处、想贴中间那一处”的场景。

图形版 Emacs 通常也能与系统剪贴板互通；终端版取决于窗口系统与配置。若发现 `C-y` 贴出来的不是你在浏览器里复制的内容，可试 `M-x clipboard-yank` 或检查 `select-enable-clipboard`。

### 5.3 插入、对调、大小写

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-o` | `open-line` | 在光标处“劈开”一行，光标留在原行 |
| `C-j` | `newline-and-indent` | 换行并按模式缩进 |
| `TAB` | 视模式而定 | 缩进当前行，或在 minibuffer 里补全 |
| `C-t` | `transpose-chars` | 交换光标左右两个字符 |
| `M-t` | `transpose-words` | 交换两个词 |
| `C-x C-t` | `transpose-lines` | 交换两行 |
| `M-u` / `M-l` / `M-c` | 大写 / 小写 / 首字母大写当前词 | |
| `C-x C-u` / `C-x C-l` | 区域变大写 / 小写 | |
| `M-q` | `fill-paragraph` | 按填充列宽重排段落（写散文、注释时常用） |
| `M-;` | `comment-dwim` | 注释或取消注释（Do What I Mean） |

`C-q`（`quoted-insert`）用于插入“本来会被当成命令的字符”，例如在文本里插入一个字面的 `C-a` 控制字符：`C-q C-a`。

## 6. 文件、缓冲区与退出

Emacs 很少“直接改磁盘上的文件”。流程是：把文件读进缓冲区 → 编辑缓冲区 → 再写回磁盘。

### 6.1 文件

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-x C-f` | `find-file` | 打开（或新建）文件 |
| `C-x C-s` | `save-buffer` | 保存当前缓冲区到对应文件 |
| `C-x s` | `save-some-buffers` | 逐个询问并保存多个改过的缓冲区 |
| `C-x C-w` | `write-file` | 另存为 |
| `C-x i` | `insert-file` | 把另一个文件的内容插入当前 point |
| `C-x C-v` | `find-alternate-file` | 用另一个文件替换当前缓冲区（开错文件时有用） |
| `C-x C-q` | `read-only-mode` | 切换只读 |
| `C-x C-c` | `save-buffers-kill-terminal` | 退出（先问未保存的） |

`C-x C-f` 在 minibuffer 里：

- `TAB` 路径补全
- `~` 表示家目录
- `/` 开头是绝对路径
- 输入一个尚不存在的文件名再回车 = 新建空缓冲区，第一次 `C-x C-s` 时才真正写盘

### 6.2 缓冲区

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-x b` | `switch-to-buffer` | 切换缓冲区（默认是上一个） |
| `C-x C-b` | `list-buffers` | 列出所有缓冲区 |
| `C-x k` | `kill-buffer` | 关闭（杀死）缓冲区，默认当前这个 |
| `C-x C-b` 后在列表里操作 | | 用 `f` 访问、`d` 标记删除、`x` 执行等（默认 buffer menu） |

建议稍后把 `C-x C-b` 换成 `ibuffer`（内置）：

```elisp
(global-set-key (kbd "C-x C-b") #'ibuffer)
```

几个你会反复见到的特殊缓冲区：

- `*scratch*`：草稿纸，默认 Lisp Interaction 模式，可直接试 Elisp
- `*Messages*`：回显区历史（`C-h e` 可打开）
- `*Help*`：帮助输出
- `*Completions*`：补全候选

未关联文件的缓冲区关闭时，内容默认就没了；有关联文件且已修改时，`C-x k` 会询问。

### 6.3 Dired：把目录当可编辑列表

`C-x d` 或对目录做 `C-x C-f` 会进入 **Dired**（目录编辑器）：

- `n` / `p` 或 `C-n` / `C-p` 移动
- `RET` 或 `f` 打开文件
- `o` 在另一窗口打开
- `^` 到上级目录
- `+` 新建目录
- `C` 复制、`R` 重命名、`D` 删除（有确认）
- `m` 标记、`u` 取消标记、`t` 反转标记
- `g` 刷新

Dired 是 Emacs “文件管理也是编辑”的典型例子：目录列表本身就是一个缓冲区。

## 7. 窗口与分屏

这里的“窗口”是 Emacs 窗格，不是操作系统窗口。

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-x 2` | `split-window-below` | 上下拆分 |
| `C-x 3` | `split-window-right` | 左右拆分 |
| `C-x 0` | `delete-window` | 关掉**当前**窗格（缓冲区还在） |
| `C-x 1` | `delete-other-windows` | 只留当前窗格 |
| `C-x o` | `other-window` | 跳到下一个窗格（可 `C-u -1 C-x o` 反向） |
| `C-M-v` | `scroll-other-window` | 滚动**另一个**窗格（对照代码/帮助时极好用） |
| `C-x +` | `balance-windows` | 让各窗格尽量等大 |
| `C-x ^` | `enlarge-window` | 加高当前窗格 |
| `C-x {` / `C-x }` | 变窄 / 变宽 | |

在**另一个窗格**里打开东西，用 `C-x 4` 前缀：

| 快捷键 | 含义 |
|--------|------|
| `C-x 4 f` | 在另一窗格打开文件 |
| `C-x 4 b` | 在另一窗格切换缓冲区 |
| `C-x 4 d` | 在另一窗格打开 Dired |

`C-x 5` 前缀则是针对新的 **frame**（再开一个操作系统窗口），例如 `C-x 5 2` 新建 frame，`C-x 5 0` 关掉当前 frame。

多窗格时 `C-x o` 要连按多次才能到目标，这是新手常见痛点。可以稍后启用内置 `windmove`，用 Shift + 方向键在窗格间移动。

## 8. 搜索与替换

### 8.1 增量搜索（Incremental Search）

这是 Emacs 最爽的功能之一：一边输入，一边跳到匹配处。

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-s` | `isearch-forward` | 向前增量搜索 |
| `C-r` | `isearch-backward` | 向后增量搜索 |
| `C-s` 再 `C-s` | | 搜同一个字符串的下一处（空搜会用上次的词） |
| `RET` | | 结束搜索，光标留在当前匹配 |
| `C-g` | | 取消搜索，光标回到搜索开始前 |
| `DEL` | | 删掉搜索串的最后一个字符 |
| `C-w` | （搜索中） | 把光标后的词追加进搜索串 |
| `C-M-s` / `C-M-r` | | 正则增量搜索 |

搜索尚未结束时，可以用 `C-s` / `C-r` 在匹配之间跳，不必先退出。

### 8.2 替换

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `M-%` | `query-replace` | 交互式替换：每个匹配问你一次 |
| `C-M-%` | `query-replace-regexp` | 正则交互替换 |
| `M-x replace-string` | | 一次性全部替换（不逐个确认） |

`query-replace` 进行中常用回答：

- `y` 或 `SPC`：替换这一处
- `n` 或 `DEL`：跳过
- `!`：剩下的全部替换，不再问
- `q` 或 `RET`：结束
- `.`：替换这一处然后结束
- `C-r`：临时进入递归编辑去看上下文，改完 `C-M-c` 回来继续替换

### 8.3 当前缓冲区里“跳到符号”

许多编程模式还提供：

- `M-.` 跳到定义（需要 tags / LSP 等后端）
- `M-,` 回到跳转前的位置（xref 栈）

对纯文本，增量搜索通常就够了。

## 9. 帮助系统：Emacs 真正的超能力

不要靠背完整键位表。**会查**比**会背**重要得多。

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `C-h ?` 或 `F1` | `help-for-help` | 帮助的帮助：列出所有 C-h 子命令 |
| `C-h t` | `help-with-tutorial` | 官方教程 |
| `C-h k` | `describe-key` | **先按它，再按你想查的键**，看这个键绑定了哪个命令 |
| `C-h c` | `describe-key-briefly` | 只在回显区显示“某键运行某命令” |
| `C-h f` | `describe-function` | 查命令/函数文档 |
| `C-h v` | `describe-variable` | 查变量 |
| `C-h m` | `describe-mode` | 当前主模式 + 次模式说明，含该模式键位 |
| `C-h b` | `describe-bindings` | 当前缓冲区全部键绑定 |
| `C-h a` | `apropos-command` | 按关键字搜命令名 |
| `C-h i` | `info` | 打开 Info 手册（Emacs 自带完整手册） |
| `C-h r` | `info-emacs-manual` | 直接进 Emacs 手册 |
| `C-h e` | `view-echo-area-messages` | 打开 `*Messages*` |
| `C-x 1` | | 看完帮助后关掉帮助窗格，只留编辑区 |

典型自学循环：

1. 模糊记得“有个命令能……”，用 `C-h a` 或 `M-x` 输入几个字母 + `TAB`
2. 对找到的命令按 `C-h f` 读文档
3. 在文档里看到默认键位，用 `C-h k` 验证
4. 在当前模式里用 `C-h m` 看这个模式改了哪些键

`C-h k` 甚至可以用来点菜单：先 `C-h k`，再用鼠标点菜单项，会告诉你该菜单对应的命令和键。

## 10. `M-x`、补全与“命令才是本体”

按 **`M-x`** 后，minibuffer 提示 `M-x`，输入命令名，`TAB` 补全，`RET` 执行。

例子：

- `M-x goto-line`
- `M-x revert-buffer`
- `M-x doctor`（内置 Eliza 心理咨询——偶尔用来确认 Emacs 还活着）
- `M-x customize` 打开自定义界面
- `M-x package-list-packages` 浏览包（需先配置软件源）

Minibuffer 里通用操作：

| 键 | 作用 |
|----|------|
| `TAB` | 尽量补全 |
| `?` | 列出可能的补全 |
| `M-p` / `M-n` | 历史记录上一条 / 下一条 |
| `C-g` | 放弃这次提问 |
| `C-a` / `C-e` | 在输入行行首 / 行尾 |

默认补全偏保守。很多新手配置会启用 `fido-mode`、`icomplete-mode` 或安装 Vertico / Ivy / Helm，让候选即时列出。这是体验跃迁最大的改动之一，但建议先用默认完成教程。

## 11. 再往前一步（仍属“常用”，不是炫技）

### 11.1 键盘宏：把重复劳动录下来

| 快捷键 | 命令 | 含义 |
|--------|------|------|
| `F3` 或 `C-x (` | `kmacro-start-macro` | 开始录制 |
| `F4` 或 `C-x )` | `kmacro-end-macro` | 结束录制 |
| `F4` 或 `C-x e` | `kmacro-end-and-call-macro` | 回放；连按继续回放 |
| `C-u 10 F4` | | 回放 10 次 |
| `C-x C-k n` | | 给宏命名，以便写入配置 |

适合“对接下来 30 行做同一组编辑”而写脚本又太重的场合。

### 11.2 书签与寄存器（知道存在即可）

- `C-x r m` 打书签，`C-x r b` 跳到书签
- 寄存器能暂存文本、窗口布局、位置：`C-x r SPC` 存位置，`C-x r j` 跳回

### 11.3 矩形编辑

对“列对齐的一块”而不是“行上的一段”：

- `C-x SPC` 进入矩形标记（`rectangle-mark-mode`）
- `C-x r k` 杀矩形，`C-x r y` 粘贴矩形
- `C-x r t` 用字符串填充矩形

### 11.4 主模式与次模式

打开 `.org` 会进 Org Mode，打开 `.c` 会进 C Mode。主模式决定缩进、语法高亮、`C-c` 前缀含义。次模式是叠加开关，例如：

- `M-x flyspell-mode` 即时拼写
- `M-x display-line-numbers-mode` 显示行号
- `M-x follow-mode` 并排两窗显示同一缓冲区的连续两页

查看当前模式：看 mode line，或 `C-h m`。

### 11.5 Org Mode 为什么常被一笔带过

很多人留下 Emacs，是因为 Org：大纲、待办、日程、代码块、导出。和本文相关的最少集合：

- `TAB` / `S-TAB` 折叠标题
- `M-RET` 新建标题或列表项
- `C-c C-t` 循环 TODO 状态
- `C-c C-e` 导出

深入 Org 是另一篇文章；先把编辑与窗口练顺，再碰它会轻松得多。

### 11.6 若你来自 Vim

可以安装 **Evil**，在 Emacs 里用 Vim 键位，同时保留 Emacs 的缓冲区、Org、Magit 等生态。这是合法且常见的路径，不是“不够纯正”。若目标是理解 Emacs 自身的操作模型，仍建议先把本文的 `C-` / `M-` 体系用一周。

## 12. 新手高频踩坑

1. **`C-h` 变成了退格**  
   某些终端把 Backspace 发成 `C-h`。可试 `M-x normal-erase-is-backspace-mode`，或在终端模拟器里改 Backspace 发送 DEL。

2. **Mac 上 Alt 打不出 Meta，反而输入特殊字符**  
   在 Terminal.app：设置里勾选 “Use Option as Meta key”。GUI 版 Emacs 一般把 Option 当 Meta，必要时可在配置里设 `mac-option-modifier`。

3. **`C-SPC` 切输入法**  
   改系统快捷键，或用 `C-@` 设 mark。

4. **`C-x C-c` 误触退出**  
   养成保存用 `C-x C-s`、离开前看一眼 minibuffer 提问的习惯。也可稍后绑定确认函数，但新手不必急。

5. **以为关掉窗格就关掉了文件**  
   `C-x 0` 只拆界面；文件还在缓冲区列表里。真正关闭是 `C-x k`，真正写盘是 `C-x C-s`。

6. **Undo 之后想 Redo**  
   标准 Emacs 没有独立的 redo 键：撤销后再做一次**新编辑**，之前的撤销本身也会进入撤销历史，表现为某种“反向撤销”。若你强烈需要 Ctrl-Z / Ctrl-Y 模型，可以之后了解 `undo-only`、`undo-redo`（较新版本）或 `undo-tree` 包。

7. **中文输入时快捷键失灵**  
   许多输入法会“吃掉”修饰键。需要按快捷键时先切回英文，或选用对修饰键更友好的输入法设置。

8. **手指酸**  
   Control 在键盘角落确实累。常见做法：系统层把 Caps Lock 映射成 Control。这几乎是 Emacs 用户的“入门装备”。

## 13. 建议的一周学习路径

| 时间 | 做什么 | 成功标准 |
|------|--------|----------|
| 第 1 小时 | `C-h t` 把官方教程做完，不跳过练习 | 能不看稿用 `C-f/b/n/p`、`C-a/e`、`C-k`、`C-y`、`C-x C-f/s` |
| 第 1 天 | 用 Emacs 写一篇日记或笔记，只用本文第 3–8 节 | 卡住会 `C-g` 和 `C-h k` |
| 第 2–3 天 | 故意分两个窗格对照编辑；用 `C-s` 代替眼睛扫视 | `C-x 2/3/o` 和增量搜索成为反射 |
| 第 4–5 天 | 用 Dired 做一次文件整理；用 `M-%` 做一次替换 | 理解 buffer ≠ window ≠ file |
| 第 6–7 天 | 读 `C-h r` 手册里 “Basic Editing” 与 “Help” 两章；考虑 Caps Lock → Ctrl | 开始用 `M-x` 发现新命令而不是先搜网页 |

刻意不要第一周就堆插件主题。键位不熟时，任何配置失败都会让你误以为“Emacs 太难”，其实只是初始化文件写坏了。

## 15. 接下来读什么

- 编辑器内：`C-h t`、`C-h r`、`C-h i`
- 官方参考卡（PDF，适合打印）：[GNU Emacs Reference Card](https://www.gnu.org/software/emacs/refcards/pdf/refcard.pdf)
- 键位记法与命令模型：手册第 5 章 *Keys and Commands*
- 想扩展时再看：`M-x customize`、`package-install`、以及一份**别人维护良好的**配置（如 Prelude、Doom、Crafted Emacs）。照抄“网上 800 行 init.el”很容易在第一周把自己锁在启动错误里。

## 结语

Emacs 的学习曲线不是“先背 200 个快捷键”，而是：

1. 建立 **命令 + 键绑定 + 帮助系统** 的心智模型；
2. 把二三十个高频动作练成反射；
3. 其余一律 `C-h` 或 `M-x` 现查。

第一周会觉得 Control 组合别扭，这是正常的。等你第一次用键盘宏把二十处重复修改在十秒内做完，或在分屏里一边看 `*Help*` 一边改配置还不丢上下文，就会明白这套模型为什么能用四十年还在长出新功能。

现在就可以打开 Emacs，按 `C-h t`。本文当作对照手册即可，不必一次读完。
