# SQLite 常用操作与维护指南

## 1. 查看表结构与 DDL 语句

### 1.1 查询系统表（跨驱动通用）
SQLite 的元数据存放在 `sqlite_master`（SQLite 3.33.0+ 别名为 `sqlite_schema`）中：

```sql
-- 获取指定表的 DDL 建表语句
SELECT sql FROM sqlite_master WHERE type = 'table' AND name = 'users';

-- 查看表及其关联的所有索引、触发器、视图 DDL
SELECT type, name, sql FROM sqlite_master WHERE tbl_name = 'users';
```

### 1.2 CLI 终端命令
进入 `sqlite3` 控制台后：

```text
.schema users
```

### 1.3 查看字段列表与元信息
```sql
-- 输出: cid | name | type | notnull | dflt_value | pk
PRAGMA table_info('users');
```

## 2. 表的修改与列操作（ALTER TABLE）

### 2.1 删除列（DROP COLUMN）

#### 现代推荐做法（SQLite 3.35.0+）
自 SQLite 3.35.0 起，原生支持直接删除列：

```sql
ALTER TABLE users DROP COLUMN age;
```
> **限制**：若列属于主键（PK）、具有外键引用、或包含在复合索引中，SQLite 会限制直接删除。

#### 兼容方案（表重建法，适用于低版本或受约束列）
```sql
BEGIN TRANSACTION;

-- 1. 新建结构（排除要删除的列）
CREATE TABLE users_new (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL
);

-- 2. 复制保留字段
INSERT INTO users_new (id, name)
SELECT id, name FROM users;

-- 3. 替换旧表
DROP TABLE users;
ALTER TABLE users_new RENAME TO users;

-- 4. 重建索引/触发器（若有）
CREATE INDEX IF NOT EXISTS idx_users_name ON users(name);

COMMIT;
```

### 2.2 添加列与重命名
```sql
-- 新增列
ALTER TABLE users ADD COLUMN email TEXT;

-- 重命名列（SQLite 3.25.0+）
ALTER TABLE users RENAME COLUMN email TO contact_email;

-- 重命名表
ALTER TABLE users RENAME TO app_users;
```

## 3. 基础数据增删改查（CRUD）

### 3.1 插入与冲突处理
```sql
-- 基础插入
INSERT INTO users (name, contact_email) VALUES ('Alice', 'alice@example.com');

-- 冲突时更新（Upsert，SQLite 3.24.0+）
INSERT INTO users (id, name, contact_email)
VALUES (1, 'Alice', 'alice_new@example.com')
ON CONFLICT(id) DO UPDATE SET contact_email = excluded.contact_email;

-- 冲突时忽略
INSERT OR IGNORE INTO users (id, name) VALUES (1, 'Alice');
```

### 3.2 查询与分页
```sql
-- 条件查询与排序
SELECT id, name FROM users WHERE contact_email IS NOT NULL ORDER BY id DESC;

-- 分页（跳过 10 条，取 5 条）
SELECT * FROM users LIMIT 5 OFFSET 10;
```

### 3.3 更新与删除
```sql
-- 更新数据
UPDATE users SET contact_email = 'updated@example.com' WHERE id = 1;

-- 条件删除
DELETE FROM users WHERE id = 1;

-- 清空全表
DELETE FROM users;
```

## 4. 索引与性能分析

```sql
-- 创建普通索引
CREATE INDEX IF NOT EXISTS idx_users_email ON users(contact_email);

-- 创建唯一索引
CREATE UNIQUE INDEX IF NOT EXISTS idx_users_name_unique ON users(name);

-- 查询执行计划（排查慢查询与全表扫描）
EXPLAIN QUERY PLAN
SELECT * FROM users WHERE contact_email = 'alice@example.com';
```

## 5. 事务控制（Transaction）

批量写入时显式开启事务，可避免频繁磁盘 I/O 刷盘（`fsync`），性能提升可达百倍以上：

```sql
BEGIN TRANSACTION;

INSERT INTO users (name) VALUES ('Bob');
INSERT INTO users (name) VALUES ('Charlie');

COMMIT; -- 若失败则执行 ROLLBACK;
```

## 6. CLI 常用点命令（Dot Commands）

在控制台终端 (`sqlite3 your_database.db`) 中可使用快捷指令：

| 命令 | 功能说明 |
| :--- | :--- |
| `.tables` | 列出当前数据库所有表名 |
| `.schema [table]` | 打印指定表（或全部表）的建表 DDL |
| `.mode table` / `.mode column` | 优化输出格式为表格或对齐列 |
| `.headers on` | 查询结果显示列头字段名 |
| `.dump [table]` | 导出完整 SQL 转储（包含表结构与 INSERT 语句） |
| `.output filename.txt` | 将后续查询结果重定向输出到文件 |
| `.exit` 或 `.quit` | 退出终端交互环境 |

## 7. 关键运行参数配置（PRAGMA）

### 7.1 开启外键约束（必须手动开启）
SQLite 默认出于向后兼容不校验外键约束，建议每次建立连接后显式启用：
```sql
PRAGMA foreign_keys = ON;
```

### 7.2 性能与并发优化：WAL 模式
开启写前日志模式（Write-Ahead Logging），显著改善读写并发冲突（读不阻塞写，写不阻塞读）：
```sql
PRAGMA journal_mode = WAL;
PRAGMA synchronous = NORMAL;
```
